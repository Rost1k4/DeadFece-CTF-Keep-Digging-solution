## 1. Вступ та опис завдання

### 2.3 За допомогою спеціального пейлоаду 
```
[...document.querySelector("body").innerText]
  .map((c, i) => ({
    i,
    char: c,
    hex: c.codePointAt(0).toString(16).toUpperCase()
  }))
  .filter(x =>
    ["200B","200C","200D","2060","FEFF","00AD"].includes(x.hex)
  )
```
